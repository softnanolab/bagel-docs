</ResponseField>

## Methods

### to_cif

Write the structure to a CIF file.

**Parameters**

<ResponseField name="filepath" type="Path" required>
  Path to the file to write the CIF structure to.
</ResponseField>

**Returns**

<ResponseField name="return" type="bool">
  True if the file was written successfully.
</ResponseField>

## Example

```python
import bagel as bg
from biotite.structure import AtomArray

chain = bg.Chain([bg.Residue(name='A', chain_ID='A', index=0)])
result = bg.oracles.FoldingResult(input_chains=[chain], structure=AtomArray(0))
```

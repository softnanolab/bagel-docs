## Example

```python
import bagel as bg
from biotite.structure import AtomArray

class DummyFoldingOracle(bg.oracles.FoldingOracle):
    def fold(self, chains: list[bg.Chain]) -> bg.oracles.FoldingResult:
        return bg.oracles.FoldingResult(input_chains=chains, structure=AtomArray(0))
```

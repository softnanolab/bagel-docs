## Attributes

<ResponseField name="input_chains" type="list[Chain]">
</ResponseField>

<ResponseField name="embeddings" type="npt.NDArray[np.float64]">
</ResponseField>

## Example

```python
import numpy as np
import bagel as bg

chain = bg.Chain([bg.Residue(name='A', chain_ID='A', index=0)])
result = bg.oracles.EmbeddingResult(
    input_chains=[chain],
    embeddings=np.zeros((1, 16), dtype=float),
)
```
